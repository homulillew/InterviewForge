# Capability claim quality

A claim must be answerable through technical reasoning: problem, mechanism, decision,
implementation, trade-off, failure, measurement, scaling or ownership. Keep the exact
resume statement and project anchor. A dependency import is a source observation,
not a capability claim. Imported interview materials remain external references.

For a Redis Lua resume bullet, probe the race condition, atomic execution boundary,
choice against conditional SQL updates, actual integration, failure/retry behavior and
validation. Do not infer that the candidate implemented every technique discussed.

Risk reasons are heuristic factors, not calibrated hiring probabilities. Evidence search
reduces uncertainty only modestly; matching source text does not prove the full claim.
