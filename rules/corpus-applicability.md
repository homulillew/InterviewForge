# Corpus applicability

Retrieve content, transitions and style through separate lanes. Resume relevance dominates
company match. Classify each pattern direct, transferable, style_only or reject. Only direct
and transferable matches can support rendered question content. Source IDs must resolve in
the pinned revision.

Direct requires relevant asserted technology. Transferable requires a compatible abstract
operator, surface and claim type; replace source technologies and assumptions with the
candidate's target. Kafka/threads can teach “why not simpler” for RAG/top_k, but Kafka-specific
semantics cannot enter the RAG question. Ownership pressure requires explicit resume ownership.

Only actual candidate answers create answer-conditioned transitions. Ordered question lists
carry weak sequence priors; unordered summaries cannot invent chains. Raw questions never
become a Top-K model prompt. Retain them locally for inspection and copy checking.
