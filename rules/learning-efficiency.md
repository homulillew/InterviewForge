# Interview-oriented learning

Default to P0/P1 and distance 0/1. P2/distance 2 requires deep-dive selection; P3 stays
outside the active plan. Extract what the turn tests, not every keyword it mentions.
Use shared graph nodes for shared mechanisms; a tree is a presentation only.

Every card has a one-liner, short mechanism/boundary explanation and likely follow-up.
Every task requires an observed weakness, a turn/retest ID and a root knowledge gap.
Simulation gaps describe missing materials or answer coverage, never a diagnosed human
weakness. Human retest can create mastery gaps. Exercises must produce reviewable evidence.

Mastery starts unknown. Neither reading a card nor an excellent generated answer proves
mastery. In the CLI, interview_ready requires the latest two assessed human retest answers to be distinct, each
explicitly reviewed >= 0.8 with no missed points. The score command only reports state.

A new unreviewed assessment or a downward review correction revokes readiness. Never keep a stale passing state by selecting older successful attempts.
