# Interview-oriented learning

Extract concepts actually tested, at most four nodes per model turn. Canonicalize aliases,
merge shared concepts and preserve claim/question/project/evidence provenance. Mechanism,
decision and failure are attack facets, not automatically separate knowledge nodes.

Default active learning: P0/P1 and distance 0/1; deep_dive includes P2/distance 2, P3 stays out.
Cards need title, one-liner, must-know mechanism, boundaries, traps, project anchors, retest
questions and actual answered FollowupQA. Do not provide only a list of unanswered follow-ups.

Tasks need observed turn/retest provenance. MaterialGap concerns sources; AnswerGap concerns
speech; MasteryGap requires evaluated human submission. Generate reviewable exercises that
can cover multiple nodes. Prefer uncovered interview benefit per estimated minute, while
preserving independent human retest evidence and recovery.

Simulation never establishes mastery. interview_ready requires the latest two distinct
assessed answers to pass explicit human review, >=0.8 and no missed points. New unreviewed
assessment or review downgrade invalidates old readiness. Never select stale passing pairs.
