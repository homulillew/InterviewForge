# Statistical style and backoff

Style controls how to challenge an assertion, not which unrelated subject to introduce.
Never hardcode company personalities. Count one independent case per duplicate group;
unordered summaries cannot teach attack style. Report sample size and confidence.

Blend increasingly broad company/role/round/seniority, company/role/round, company/role,
company, role/round, role and global profiles. Small groups contribute only weak weight.
Store the effective weights and backoff path. neutral mode has no style prior even when
content patterns are available. Missing profiles yield zero confidence, not invented style.

Pin immutable corpus revision, database identity and profile IDs at session creation.
New imports do not alter old sessions. Validate style against the pinned statistics on
continuation. This heuristic is not calibrated company behavior; empirical calibration
requires independent human-labeled evaluation data.
