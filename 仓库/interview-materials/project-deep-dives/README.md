[跨项目八股串讲与复习索引](P02-P04_八股串讲与复习索引.md) 包含 Attention/GQA、四类 mask、采样与信用层次、自然追问映射及练习顺序。

基础篇附手算与综合练习，进阶篇附改选条件和高压分支。简历决定项目事实前提，面经提供问法；代码与通用知识用于回答准备，推演和实验边界在附录单列。

这是编写的学习材料，未运行自动双 Agent 会话、未执行目标项目训练，也不代表真人已通过复测。本目录的问答、索引和材料依据纳入版本管理；原始简历、面经附件及克隆的项目源码保留在本地并由 Git 忽略。

文档正文可以直接在 GitHub 阅读。附录中的简历、面经和项目源码相对链接用于本地溯源，需要准备对应文件；JSON 中的材料路径和哈希也指向编写时的本地输入。`P02-P04_整理检查.json` 记录推送前的整理检查，其 `not_executed` 描述该次检查的执行范围。
